# Glossary

What Prospector's words are in each language, for whoever translates the app (`web/lang/<locale>.json`) or the server (`internal/say/lang/<locale>.json`). Use these words for these things, everywhere, so a page, its mail and its errors agree. A term not here is translated as the language would say it.

## Never translated

Prospector, LinkedIn, GitHub, Google, Okta, Entra ID, Postmark, SearXNG, Claude and other product names; API, MCP, OpenAPI, SQL, CSV, URL; scope names (`read`, `agents:run`…) and tool names; anything in `{braces}`, ICU `plural`/`select` keywords and their option keys (except plural categories, which follow the language), tags such as `<link>…</link>`, and Go verbs (`%s`, `%d`, `%[2]d`).

## Voice

Plain, short, friendly and businesslike, as the English is. Address the reader as:

| Language | Address               | Notes                                                                        |
| -------- | --------------------- | ---------------------------------------------------------------------------- |
| es       | tú                    | Spain Spanish.                                                               |
| de       | Sie                   | Nouns capitalised; prefer short compounds.                                   |
| fr       | vous                  | A non-breaking space before `: ; ? !`.                                       |
| ja       | です・ます            | No spaces between words; full-width punctuation `。、：`.                    |
| it       | tu                    |                                                                              |
| nl       | je                    |                                                                              |
| pt       | tu                    | European Portuguese (pt-PT): _ecrã_, _ficheiro_, _utilizador_, _definições_. |
| sv       | du                    |                                                                              |
| pl       | ty                    | All plural forms: `one`, `few`, `many`, `other`.                             |
| da       | du                    |                                                                              |
| nb       | du                    | Bokmål.                                                                      |
| fi       | (sinä, or impersonal) | Prefer impersonal forms where English says "you".                            |

Plural forms: give every CLDR category the language has (ja only `other`; pl `one`, `few`, `many`, `other`; the rest `one` and `other`). Keep `#` and the value names as they are.
